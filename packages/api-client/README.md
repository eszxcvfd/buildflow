# @buildflow/api-client

Auto-generated TypeScript client for the BuildFlow REST API
(`/api/v1`). Source of truth is `apps/api` and its OpenAPI document.

`src/index.ts` is the only hand-written entry point. Anything under
`src/generated/` is owned by `openapi-typescript` and is **never** edited
by hand.

Regeneration:

```sh
pnpm --filter @buildflow/api-client generate
```
